# Gauge Research Module

## Status

Research-only planning note. This directory is not a formal Qt runtime module and contains no copied model, dataset, annotation, training run or third-party source.

## Future Public Scope

Only content that is original, configurable and independently reviewed may be added:

- Algorithm explanations.
- Profile schema documentation with non-private example values.
- Public-safe demonstration scripts that do not depend on private absolute paths.
- Synthetic or rights-cleared visualization examples.
- Evaluation limits and reproducibility notes.

## Excluded Scope

Private gauge images, annotations, model weights, runs, virtual environments, cache, logs and external repository code remain outside the public repository.
